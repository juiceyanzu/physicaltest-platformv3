```

├── src/              # 源代码
```

## 🚀 运行步骤

### 1. 环境准备

**前提条件**：
- Node.js 14.0 或更高版本
- npm 6.0 或更高版本
- 微信开发者工具

### 2. 安装依赖

```bash
# 进入小程序目录
cd miniprogram

# 安装依赖
npm install
```

### 3. 配置 AppID

**步骤**：
1. 打开 `miniprogram/manifest.json` 文件
2. 找到 `mp-weixin` 部分
3. 填入你的微信小程序 AppID：

```json
{
  "mp-weixin": {
    "appid": "你的AppID"
  }
}
```

**注意**：如果没有 AppID，可以使用测试号（在微信开发者工具中选择"测试号"）。

### 4. 启动开发服务器

```bash
# 启动微信小程序开发服务器
npm run dev:mp-weixin
```

**预期输出**：
- 开发服务器启动成功
- 显示编译进度
- 构建完成后显示 "Build completed"

### 5. 在微信开发者工具中打开

**步骤**：
1. **打开微信开发者工具**
2. **选择"导入项目"**
3. **项目目录**：选择 `C:\code\physicaltest-platformv2\miniprogram\dist\dev\mp-weixin`
4. **AppID**：填入你的微信小程序 AppID（或选择"测试号"）
5. **点击"导入"**

## 🔧 开发流程

### 1. 修改代码

编辑 `src` 目录下的文件，开发服务器会自动编译并更新。

### 2. 预览和调试

- **预览**：在微信开发者工具中点击"预览"按钮，生成二维码
- **真机调试**：点击"真机调试"按钮，使用手机扫码进行调试
- **控制台**：使用微信开发者工具的控制台查看日志和错误

### 3. 构建生产版本

```bash
# 构建生产版本
npm run build:mp-weixin
```

构建完成后，生产版本会输出到 `miniprogram/dist/build/mp-weixin` 目录。

## 🐛 常见问题及解决方案

### 1. 登录失败
**问题**：使用测试账号登录失败
**解决方案**：确保使用正确的测试账号，密码可以输入任意值

### 2. 页面加载失败
**问题**：页面显示"页面不存在"
**解决方案**：检查开发服务器是否运行，确保路径正确

### 3. 样式错误
**问题**：页面样式显示异常
**解决方案**：检查 WXSS 文件，确保语法正确，避免使用复杂的 CSS 渐变

### 4. 数据不显示
**问题**：页面数据不显示
**解决方案**：检查 store 文件中的模拟数据，确保数据格式正确

### 5. 微信登录失败
**问题**：微信一键登录失败
**解决方案**：确保在微信开发者工具中登录了微信账号，且 AppID 配置正确
